# Temperaturumrechner

Ein kleines Python-Übungsprojekt für die Konsole. Das Programm rechnet Temperaturen von Celsius in Fahrenheit und von Fahrenheit in Celsius um.


## Dabei geübt

- Benutzereingaben mit input()
- while-Schleifen und Bedingungen mit if und elif
- Variablen und einfache mathematische Berechnungen
